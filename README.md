# Kiezküche

## Beschreibung

Kiezküche ist ein Webprojekt, das mit HTML, CSS und JavaScript umgesetzt wird. Die grundlegende Projektstruktur dient als Ausgangspunkt für die weitere Entwicklung.

## Starten

Die Webseite kann geöffnet werden, indem die Datei `index.html` im Browser geöffnet wird.

Alternativ kann die Webseite mit der VS-Code-Erweiterung Live Server gestartet werden.
